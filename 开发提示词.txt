
请开发一个名为 PromptClip｜提示词剪刀 的本地前端小工具，用于低龄小朋友快速选择提示词卡片、一键复制给 AI 绘画工具。

项目定位：
这是一个面向 6-12 岁低龄儿童的提示词剪切/拼装工具。孩子不会打字，也可以通过点击卡片，完成“画什么 + 画成什么样 + 细节”的提示词组合。

请优先做一个可运行的 MVP，不要接后端，不要接大模型 API。所有数据先写在前端本地，支持 localStorage 保存。

技术要求：
1. 如果当前目录没有项目，请初始化 Vite + React + TypeScript 项目。
2. 不要使用复杂 UI 库，使用原生 CSS 或 CSS Modules 即可。
3. 项目能通过 npm install 和 npm run dev 启动。
4. 页面适配电脑和平板，低龄孩子也能看清楚按钮。
5. 代码结构清晰，组件拆分合理。

核心功能：
1. 顶部展示公式：
   提示词 = 画什么 + 画成什么样 + 细节

2. 页面主体分为三列：
   - ① 主体（画什么）
   - ② 风格（画成什么样）
   - ③ 细节（还有什么）

3. 每一列使用大号卡片按钮展示词条，孩子点击即可选中。
   - 主体只能选择 1 个
   - 风格可以选择 1 个
   - 细节可以选择多个

4. 选中后实时生成完整提示词，例如：
   请画一只小牦牛，使用可爱卡通风格，画面中加入五色经幡、远处雪山、主体居中，整体温暖明亮，适合低龄儿童 AI 创作。

5. 生成区需要有这些按钮：
   - 复制给 AI
   - 换一组灵感
   - 清空选择

6. 复制成功后有明显提示：
   已复制，可以粘贴给 AI 了！

7. 增加“课堂模板”功能，至少内置 4 个模板：
   - 高原动物徽章
   - 石渠文创明信片
   - 藏文化角色设计
   - 星空草原插画

8. 增加“老师模式”开关。
   老师模式打开后，可以：
   - 新增主体词
   - 新增风格词
   - 新增细节词
   - 删除自定义词
   - 数据保存到 localStorage
   - 一键恢复默认词库

9. 增加“导出词库 JSON”和“导入词库 JSON”功能，方便老师备份课堂词库。
